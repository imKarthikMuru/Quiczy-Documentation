# Category Management & Visual Sorting

Categories organize products into logical tabs on the Billing Screen (e.g. *Appetizers*, *Main Course*, *Desserts*, *Beverages*, *Retail Merch*), enabling fast, mistake-free cashier entry.

---

## 🏷️ Category Configuration

1. Navigate to **Inventory** → **Categories**.
2. Tap **+ Add Category**.
3. **Category Details**:
   - **Category Name**: (e.g., `Beverages`).
   - **Color Code & Icon**: Assign a distinct color badge (e.g., Blue for Drinks, Orange for Fast Food) for fast visual recognition.
   - **Display Order**: Numerical sort priority determining tab order on the billing screen.
   - **Parent Category (Optional)**: Build nested hierarchies (e.g. *Beverages* → *Hot Coffee*).
4. Tap **Save Category**.

---

## 🔐 Required Permissions
- `canManageCategories` (<span className="badge-role">OWNER</span> <span className="badge-role">ADMIN</span>)
