# Modifier Groups & Attribute Configuration

Modifier Groups allow managers to create reusable sets of options, toppings, sides, and customizations that can be attached to multiple products.

---

## 🛠️ Creating a Modifier Group

1. Navigate to **Inventory** → **Modifiers**.
2. Tap **+ Create Modifier Group** (e.g., `Pizza Toppings`, `Steak Temperature`, `Coffee Milk Options`).
3. **Group Rules**:
   - **Selection Type**: `Single Choice (Radio)` or `Multi-Choice (Checkbox)`.
   - **Min / Max Selections**: (e.g. Min: 1, Max: 1 for Sizes; Min: 0, Max: 5 for Toppings).
   - **Mandatory**: When checked, the POS will not allow adding the product until a selection is made.
4. **Options & Pricing**:
   - Add individual choices with their additional price surcharge (e.g., `Almond Milk +$0.75`, `Soy Milk +$0.50`).
5. **Attach to Products**:
   - Select which categories or specific items this modifier group applies to.
6. Tap **Save Group**.
