# App Preferences & Terminal Settings

Customize local terminal behavior, audio feedback sounds, auto-lock timeouts, auto-sync intervals, and hardware integrations.

---

## ⚙️ Terminal Preference Toggles

Navigate to **Settings** → **App Settings**:

| Preference | Options / Range | Description |
| :--- | :--- | :--- |
| **Sound Effects** | `Enabled` / `Disabled` | Plays audible confirmation chimes on barcode scan, payment success, and sync events. |
| **Auto-Lock Screen Inactivity** | `Off`, `1 min`, `2 min`, `5 min`, `15 min` | Automatically locks the screen to the [Fast PIN Screen](../getting-started/staff-selection.md) when the register is left unattended. |
| **Auto-Sync Interval** | `1 min`, `5 min`, `15 min`, `Manual Only` | Background synchronization polling frequency with the cloud database. |
| **KDS Warning Timer** | `5 to 30 minutes` | Elapsed preparation time threshold before KDS order cards turn yellow/warning. |
| **KDS Urgent Timer** | `15 to 60 minutes` | Elapsed preparation time threshold before KDS order cards turn red/urgent. |
| **Auto-Print Receipt on Tender** | `Enabled` / `Disabled` | Automatically triggers receipt print without pressing additional buttons. |
| **Auto-Open Cash Drawer** | `Enabled` / `Disabled` | Pulses RJ11 cash drawer on cash transactions. |
