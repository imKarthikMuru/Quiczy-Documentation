# Interactive Floor Plan & Table Status

The **Floor Plan** in Quiczy POS provides full-service dining establishments with a live, 2D visual map of the restaurant floor divided into custom dining sections (e.g. *Main Hall*, *AC Dining*, *Outdoor Patio*, *Rooftop Lounge*).

---

## 🎨 Color-Coded Table Statuses

Every table tile on the floor plan indicates real-time operational status through universal color coding:

| Status Badge | Color Code | Description | Next Action |
| :--- | :--- | :--- | :--- |
| **Available** | 🟢 Green | Table is vacant, cleaned, and ready to seat incoming guests. | Tap to open new table order. |
| **Occupied / Seated** | 🔵 Blue | Guests are seated; initial drinks or appetizers are being ordered. | Tap to add items or send KOT. |
| **Kitchen In-Prep** | 🟠 Orange | KOT has been fired to the kitchen; food is currently being cooked. | Tap to check timer or fire round 2. |
| **Billed / Settlement** | 🟣 Purple | Pro-forma bill has been printed and handed to the guests. | Tap to collect payment and close tab. |
| **Reserved** | 🟡 Yellow | Table is booked for an upcoming reservation. | Tap to seat arriving reserved party. |

---

## ⏱️ Live Table Timer Badges

Each occupied table displays a live timer badge indicating elapsed dining time:
- **0 - 30 mins**: Normal dining progression (Standard color).
- **30 - 60 mins**: Service check reminder.
- **60+ mins**: Long-occupancy alert for floor captains and managers.

---

## 🧭 Multi-Section Navigation

Use the top section tabs to toggle between different restaurant floors or dining areas. Each section maintains independent grid layouts, table numbers, and seating capacities.
