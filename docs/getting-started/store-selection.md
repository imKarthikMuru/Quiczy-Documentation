# Multi-Store & Branch Selection

Quiczy POS supports multi-location franchise management from a single account. If your organization operates multiple physical outlets, branches, or pop-up stores, the **Store Selection** screen lets operators select which location this device serves.

---

## 📸 Screen Overview

![Store Selection Screen](/screenshots/getting-started/store-selection.png)

_Figure 1: Store Selection Screen displaying branch locations and active status._

---

## 🏢 Screen Components & Actions

1. **Search Bar (`Q Search for a Store location...`)**: Instantly filters large store lists by store name, address, or branch code.
2. **Store Cards**: Each card displays:
   - **Store Name** (e.g., `MK Traders Hardwares` or `Downtown Bistro`)
   - **Location / Address** (e.g., `OM Sakthi Nagar`)
   - **Status Badge** (`• ACTIVE` / `INACTIVE`)
3. **Next Button (`→ NEXT`)**: Confirms the selected store and advances to [Terminal Selection](terminal-selection.md) or [Staff Selection](staff-selection.md).

---

## 🔄 Single Store vs. Multi-Store Behavior

- **Single Store Accounts**: If your organization has only one active store configured, Quiczy POS automatically selects the default store and streamlines navigation directly to Terminal or Staff Selection.
- **Multi-Store Accounts**: Staff must select their branch before commencing their shift to ensure inventory deductions, tax rules, and receipt numbering correspond to the correct branch entity.

---

## 🔐 Required Permissions
- Access to the Store Selection screen requires an authenticated account with permission to operate within the selected branch.
