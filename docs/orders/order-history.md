# Order History, Search & Audit

The **Order History** screen maintains a complete ledger of every sale, order modification, tender split, cancellation, and refund processed by your store.

---

## 🔍 Finding Past Orders

Use the top search and filter bar to locate past transactions:
- **Search by Invoice Number**: Type any partial or full order ID (e.g. `INV-042`).
- **Search by Customer**: Type customer name or phone number.
- **Filter by Status**:
  - `All Orders`
  - `Completed / Paid`
  - `Held / Parked`
  - `Cancelled / Voided`
  - `Refunded (Full / Partial)`
- **Filter by Date Range**: Today, Yesterday, This Week, Custom Calendar Date Range.

---

## 📄 Order Details Inspection

Tapping on any order card in the left list opens the comprehensive right-hand inspection drawer:
- **Order Header**: Order ID, Table #, Channel (Dine-In / Takeaway), Cashier, Server, Timestamp.
- **Itemized Breakdown**: List of products, quantity, unit price, applied modifiers, and kitchen notes.
- **Financial Summary**: Subtotal, discount names & values, composite tax breakdowns (CGST/SGST/VAT), and net grand total.
- **Payment Log**: Breakdown of tenders used (e.g. `$20 Cash + $28.50 Card`).

---

## 🛠️ Available Order Actions

- **Reprint Bill**: Prints a duplicate receipt on the default receipt printer.
- **Issue Refund**: Initiates the [Refund Workflow](refunds-cancellations.md).
- **Share Digital Invoice**: Sends receipt via WhatsApp or Email.
