# Supported Payment Methods & Gateways

Quiczy POS accommodates multiple payment methods to ensure frictionless customer settlement across cash, card, contactless, UPI QR, and gift vouchers.

---

## 💳 Payment Method Breakdown

| Tender Method | Processing Type | Offline Supported? | Hardware Required |
| :--- | :--- | :--- | :--- |
| **💵 Cash** | Local Ledger | ✅ 100% Offline | Cash Drawer (RJ11/RJ12) |
| **📱 Dynamic UPI QR** | Customer Mobile Scan | ✅ Offline (via Merchant Soundbox/SMS) | Customer-facing screen / POS screen |
| **💳 Card / EDC Terminal** | External POS Terminal / Swiper | ✅ External EDC handles network | External Swiper / Card Machine |
| **⚖️ Split Tender** | Multi-Instrument Combination | ✅ 100% Offline | Cash drawer & terminal |
| **🎁 Custom / Gift Card** | Store Credit / Voucher Code | ✅ 100% Offline | POS Terminal |

---

## ⚙️ Enabling & Disabling Payment Methods

Store administrators can enable or disable specific payment instruments (e.g. disabling checks or enabling UPI) under **Settings** → **Payment Settings**.
